# 📁 FILE MANAGEMENT SYSTEM

## 📌 Project Overview
This project is a desktop-based File Management System developed using Python and Tkinter. It provides a simple graphical interface that helps users perform different file operations such as creating, reading, editing, renaming, deleting, and managing files efficiently. The application also handles file permissions and automatically creates a dedicated folder on the Desktop for storing files.



## ⚙️ Main Features
- Create and manage text files
- Read and display file contents
- Write data using append or overwrite modes
- Rename existing files
- Delete unwanted files
- View all available files
- Manage file permissions (Read Only / Read & Write)
- User-friendly graphical interface



## 📋 Functional Requirements
- Create new files
- Read existing files
- Edit and save file data
- Support append and overwrite modes
- Rename and delete files
- Display all stored files
- Maintain read-only and read-write permissions
- Automatically create FMS folder on Desktop

## ▶️ Running the Project

### 🚀 Method 1: Executable Version
1. Open the `dist` or `Release` folder
2. Double-click `main.exe`
3. The application will start automatically

✔ No Python installation required



### 💻 Method 2: Source Code
1. Install Python on your system

2. Install required library:

```bash
pip install pillow
```

3. Run the project:

```bash
python main.py
```
